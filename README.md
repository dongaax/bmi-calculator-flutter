# BMI Calculator

A Flutter app that calculates Body Mass Index (BMI) from height and weight, and shows the result with a color-coded category.

## Features
- Enter height (cm) and weight (kg)
- Calculates BMI and shows the category: Underweight, Normal, Overweight, Obese
- Input validation with an error message for empty or invalid values
- Reset button to clear the fields
- Dark UI with a blue and black theme

## How to Run
1. Clone the repository: git clone https://github.com/dongaax/bmi-calculator-flutter.git
2. Go to the project folder: cd bmi-calculator-flutter
3. Install packages: flutter pub get
4. Run the app: flutter run
